## What is not yet done — current target
**Energy & Report section — five new HTML pages.** These pages introduce the energy monitoring and reporting layer of the BLENDY portal:

- **`energy_overview.html`** — Energy section landing page. Shows a building-scoped energy summary: KPI cards (consumption, cost, benchmark), a time-series trend chart placeholder, and a period selector (daily/weekly/monthly). Entry point for energy monitoring.
- **`energy_detail.html`** — Detailed energy breakdown page. Drills into specific energy meters or systems (HVAC, lighting, etc.) with a table of meter readings and a chart placeholder.
- **`report_list.html`** — Report library landing page. Lists all generated reports as table rows: report name, type, building, date generated, status badge, and download/view action buttons.
- **`report_detail.html`** — Individual report view. Shows report metadata (name, building, period, generated by, date) and a structured content area with section headings, data tables, and chart placeholders.
- **`report_export.html`** — Report export/generation form. Fields: report type, building, date range, output format (PDF/CSV/Excel).

## Important implementation notes
- All pages are **building-scoped** — resolve the active building context consistently with existing views.
- Templates must extend `base.html` or `base2.html` and use the existing BLENDY CSS tokens; no new CSS files unless strictly necessary.
- Follow existing visual patterns: KPI cards from `dashboard.html`; list-view card+table from `clients.html`/`users.html`; form card from `user_detail.html`; split-panel from `objects.html`.
- URL patterns: `/energy/`, `/energy/<int:building_pk>/detail/`, `/reports/`, `/reports/<int:pk>/`, `/reports/export/`.
- Start with layout-first (static/sample data) pages; backend wiring is a subsequent step.
