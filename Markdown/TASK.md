# TASK

## Current task
Build the **Energy & Report section layout** — new HTML pages:
`energy_overview.html`, `energy_detail.html`, `report_list.html`, `report_detail.html`, `report_export.html`.

## Immediate objective
Create layout-first pages for the Energy & Report section using static/sample data. All pages must fit seamlessly into the existing BLENDY portal shell and visual language. Backend wiring (queryset-backed data, chart data from real DB, export generation) is a **subsequent step** and is out of scope here.

Specific targets:

- **`energy_overview.html`** — Energy section landing page. Shows a building-scoped energy summary: KPI cards (consumption, cost, benchmark), a time-series trend chart placeholder, and a period selector (daily/weekly/monthly). Follows the `dashboard.html` KPI + chart layout pattern.
- **`energy_detail.html`** — Detailed energy breakdown page. Drills into specific energy meters or systems (HVAC, lighting, etc.) with a table of meter readings and a chart placeholder. Follows the `objects.html` split-panel pattern.
- **`report_list.html`** — Report library landing page. Lists all generated reports as table rows: report name, type, building, date generated, status badge, and download/view action buttons. Follows the `clients.html` list-view card + table pattern.
- **`report_detail.html`** — Individual report view. Shows report metadata (name, building, period, generated by, date) and a structured content area with section headings, data tables, and chart placeholders. Follows the `building_report.html` layout pattern.
- **`report_export.html`** — Report export/generation form. Fields: report type (dropdown), building, date range, output format (PDF/CSV/Excel). Follows the `user_detail.html` form card pattern.
